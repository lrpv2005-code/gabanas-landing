# Gabanas Pizza - Landing Page Comercial

Página web estática y responsiva desarrollada para un restaurante local. El objetivo fue crear una presencia digital rápida y visualmente atractiva para redirigir a los clientes a los canales de atención y pedidos.

## Características Principales
- **Diseño nativo:** Maquetación construida desde cero con CSS Grid y Flexbox, sin depender de frameworks externos.
- **Rendimiento:** Sitio estático construido puramente con HTML y CSS para garantizar tiempos de carga mínimos, totalmente optimizado para navegación móvil.
- **Interactividad:** Diseño visual con tema oscuro, usando propiedades avanzadas de CSS3 para crear animaciones, efectos hover y transiciones fluidas.
- **Conversión:** Enlaces directos hacia WhatsApp y redes sociales para centralizar la recepción de pedidos locales.

## Tecnologías Utilizadas
- **HTML5** para la estructura del sitio.
- **CSS3** para los estilos, empleando variables, Grid, Flexbox y animaciones nativas.
- **FontAwesome v6.2.1** importado por CDN para los iconos.

## Cómo visualizar el proyecto
Este es un proyecto estático. Todos los recursos multimedia, como las imágenes y los videos del restaurante, están guardados de forma local dentro de los archivos del proyecto, por lo que no necesitas instalar servidores ni dependencias para correrlo.

Para verlo funcionando, sigue estos pasos:
1. Clona este repositorio en tu computadora.
2. Entra a la carpeta del proyecto.
3. Abre el archivo `index.html` directamente en tu navegador web.
